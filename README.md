# workbench

Private working repo for things built with Claude that are worth keeping and versioning: prompts, settings, small scripts and plain-text notes.

## What goes where

| Folder | Contents |
| --- | --- |
| `overnight-brief/` | Prompt and settings for the daily 4am briefing |
| `inbox-cleanup/` | Gmail cleanup rules and prompt |
| `notes/` | Plain-text notes worth keeping a history of |
| `scratch/` | One-off outputs; safe to delete at any time |

## Rules

- Personal material only. Nothing from an employer: no internal research, models or anything derived from them.
- No passwords, API keys or tokens, ever. A private repo is not a vault.
- Documents, spreadsheets and decks do not live here. This repo is for code, configuration, prompts and text.
- A folder becomes its own repo only when it needs its own automation, needs to be shared, or has outgrown this one.
